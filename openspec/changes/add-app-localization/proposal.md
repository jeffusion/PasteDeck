# Change: 增加中英日俄本地化能力

## Why

PasteDeck 当前没有本地化资源体系，用户可见文本直接散落在 SwiftUI、AppKit、模型和服务代码中，并同时使用中文和英文。即使系统语言是中文，空状态和卡片菜单仍会显示英文；切换到英文、日语或俄语时，设置页、权限引导、计数、时间和辅助功能语义也不会随语言变化。

这不是逐个替换文案即可解决的问题。应用还需要统一语言回退、动态格式与复数规则，并确保 SwiftPM 构建和手工生成的 `.app` 都真正包含本地化资源。

## What Changes

- 增加英语 `en`、简体中文 `zh-Hans`、日语 `ja`、俄语 `ru` 四套完整本地化资源，以英语作为开发语言和最终回退语言。
- 应用遵循 macOS 系统语言和“按 App 设置”的首选语言；本阶段不增加应用内语言选择器。
- 建立统一的本地化访问层，将抽屉、菜单、卡片、空状态、设置、权限引导、对话框、辅助功能文本以及用户可见错误从硬编码字符串迁移为稳定 key。
- 将内容类型、筛选名称、相对时间、字节大小、字符数、文件数和条目数改为与当前 App 语言一致的格式化输出，并为四种语言提供正确复数规则。
- 更新应用打包流程，声明支持语言并把 `.lproj` 资源复制到 `.app/Contents/Resources`。
- 增加资源完整性、格式参数、回退行为、打包结果和硬编码回归检查。

## Impact

- **Affected capability:** 新增 `app-localization`。
- **Affected code:** `Sources/PasteDeck/App`、`Models`、`Services`、`Views` 中所有用户可见文本及其格式化逻辑。
- **Affected build:** `Package.swift`、`Makefile` 和 `Resources`。
- **Affected tests:** 模型展示字符串测试、视图模型相关断言及新增本地化资源测试。
- **Data compatibility:** 不修改剪贴板数据模型、Core Data schema、用户设置或持久化格式。
- **Interaction compatibility:** 不改变抽屉、搜索、筛选、卡片、快捷键和权限流程的行为，只替换其展示语言和 locale-aware 格式。

## Non-Goals

- 不支持繁体中文及中、英、日、俄之外的翻译。
- 不增加应用内语言选择器或无需重启的运行时语言切换。
- 不翻译用户复制的内容、文件名、应用名、标签、备注、产品名 `PasteDeck`、快捷键符号、文件扩展名和开发者日志。
- 不借本次本地化改造重排界面、改变控件尺寸或实现尚未完成的设置功能。
