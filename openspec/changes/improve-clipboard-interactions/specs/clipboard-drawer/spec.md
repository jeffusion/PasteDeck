## ADDED Requirements

### Requirement: 左侧锚定的搜索控件

抽屉搜索控件 MUST 固定其左边界，并仅向右展开。

#### Scenario: 用户展开搜索控件

- **WHEN** 用户激活折叠状态的搜索按钮
- **THEN** 搜索控件从 32pt 向右展开到 200pt
- **AND** 搜索控件左边界保持不变
- **AND** 输入焦点进入搜索文本框

#### Scenario: 用户使用辅助技术访问搜索

- **WHEN** 搜索控件处于折叠状态
- **THEN** 系统将其暴露为可操作按钮
- **AND** 系统提供“搜索剪贴板历史”的辅助功能标签和 tooltip

### Requirement: 持久可见的置顶状态

卡片 MUST 使用图钉图标持续表达置顶状态，且不得只依赖颜色。

#### Scenario: 卡片已置顶

- **WHEN** 卡片的 `isPinned` 为 true
- **THEN** 卡片标题栏时间左侧显示白色 `pin.fill`
- **AND** 辅助功能状态包含“已置顶”
- **AND** 卡片仍按现有规则排列到未置顶卡片之前

#### Scenario: 卡片取消置顶

- **WHEN** 卡片的 `isPinned` 从 true 变为 false
- **THEN** 图钉图标消失
- **AND** 类型标识和时间不因固定图钉槽位而跳动

#### Scenario: 减少置顶状态动画

- **WHEN** 系统的减少动态效果设置已启用
- **AND** 卡片的置顶状态发生变化
- **THEN** 图钉状态仅使用透明度变化
- **AND** 图钉状态不使用缩放动画

### Requirement: 最小必要卡片滚动

抽屉 MUST 只滚动到足以让所选卡片完整可见的位置，不得默认将所选卡片居中。

#### Scenario: 所选卡片已完整可见

- **WHEN** 用户选择视窗内完整可见的卡片
- **THEN** 横向滚动位置保持不变

#### Scenario: 所选卡片被视窗边缘裁切

- **WHEN** 用户选择左侧或右侧未完整可见的卡片
- **THEN** 抽屉仅滚动到该卡片完整可见
- **AND** 抽屉不强制将该卡片居中

#### Scenario: 用户通过键盘选择卡片

- **WHEN** 用户使用左右方向键选择卡片
- **THEN** 抽屉应用与鼠标选择相同的最小必要滚动规则

#### Scenario: 用户启用减少动态效果

- **WHEN** 系统的减少动态效果设置已启用
- **THEN** 卡片可见性调整不使用滚动动画
