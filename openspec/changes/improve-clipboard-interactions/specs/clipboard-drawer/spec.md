## ADDED Requirements

### Requirement: 左侧锚定的搜索控件

抽屉 MUST 保持“搜索框 + 分类按钮 + 数量”整组的原居中基准；搜索控件 MUST 固定折叠态左边界，并仅向右展开。

#### Scenario: 用户展开搜索控件

- **WHEN** 用户激活折叠状态的搜索按钮
- **THEN** 折叠态的“搜索框 + 分类按钮 + 数量”整组以抽屉为中心
- **AND** 搜索控件从 34pt 向右展开到 210pt
- **AND** 搜索控件左边界保持不变
- **AND** 输入焦点进入搜索文本框

#### Scenario: 用户使用辅助技术访问搜索

- **WHEN** 搜索控件处于折叠状态
- **THEN** 系统将其暴露为可操作按钮
- **AND** 系统提供“搜索剪贴板历史”的辅助功能标签和 tooltip

### Requirement: 持久可见的置顶状态

卡片 MUST 使用图钉图标持续表达置顶状态，且不得只依赖颜色。

#### Scenario: 卡片已置顶

- **WHEN** 卡片的 `isPinned` 为 true
- **THEN** 卡片标题栏的类型文字右侧显示白色 `pin.fill`
- **AND** 辅助功能状态包含“已置顶”
- **AND** 卡片仍按现有规则排列到未置顶卡片之前

#### Scenario: 卡片取消置顶

- **WHEN** 卡片的 `isPinned` 从 true 变为 false
- **THEN** 图钉图标消失
- **AND** 未激活状态不保留空白占位
- **AND** 时间行保持从左侧连续显示

#### Scenario: 减少置顶状态动画

- **WHEN** 系统的减少动态效果设置已启用
- **AND** 卡片的置顶状态发生变化
- **THEN** 图钉状态仅使用透明度变化
- **AND** 图钉状态不使用缩放动画

### Requirement: 最小必要卡片滚动

卡片区域上下左右 MUST 使用统一的 16pt padding。抽屉 MUST 使用动画滚动到足以让所选卡片及其 16pt 边缘间隙完整可见的位置，不得默认将所选卡片居中。仅在系统开启减少动态效果时取消动画。

#### Scenario: 卡片区域保持统一边距

- **WHEN** 抽屉显示卡片区域
- **THEN** 首尾卡片与左右视窗边界保留 16pt 间隙
- **AND** 卡片与卡片区域上下边界保留 16pt 间隙

#### Scenario: 所选卡片已完整可见

- **WHEN** 用户选择视窗内完整可见的卡片
- **AND** 卡片与左右视窗边界均至少保留 16pt 间隙
- **THEN** 横向滚动位置保持不变

#### Scenario: 所选卡片被视窗边缘裁切

- **WHEN** 用户选择左侧或右侧未完整可见的卡片
- **THEN** 抽屉使用 250ms 缓动动画，仅滚动到该卡片及其 16pt 边缘间隙完整可见
- **AND** 抽屉不强制将该卡片居中

#### Scenario: 所选卡片可见但边缘间隙不足

- **WHEN** 用户选择完整可见但距离左侧或右侧视窗边界不足 16pt 的卡片
- **THEN** 抽屉使用 250ms 缓动动画执行最小必要滚动
- **AND** 滚动结束后卡片与对应视窗边界保留至少 16pt 间隙

#### Scenario: 用户通过键盘选择卡片

- **WHEN** 用户使用左右方向键选择卡片
- **THEN** 抽屉应用与鼠标选择相同的最小必要滚动规则

#### Scenario: 用户启用减少动态效果

- **WHEN** 系统的减少动态效果设置已启用
- **THEN** 卡片可见性调整不使用滚动动画

### Requirement: 非阻塞卡片预览

抽屉 MUST 避免在卡片滚动和视图重绘路径中同步解码原始图片或读取文件系统元数据，并 MUST 避免对每张卡片叠加动态背景材质。

#### Scenario: 图片卡片进入可见区域

- **WHEN** 图片卡片首次进入可见区域
- **THEN** 系统在后台将原图下采样为最长边不超过 360px 的预览
- **AND** 主线程只更新已生成的预览和图片尺寸文本
- **AND** 后续显示同一卡片时优先使用进程内缓存

#### Scenario: 文件卡片进入可见区域

- **WHEN** 文件卡片首次进入可见区域
- **THEN** 系统在后台读取文件大小和扩展名
- **AND** 后续视图重绘不重复访问文件系统

#### Scenario: 用户持续横向滚动

- **WHEN** 多张卡片依次经过鼠标指针
- **THEN** Hover 状态不缩放卡片或改变阴影半径
- **AND** 卡片不创建额外的 backdrop material 层

### Requirement: 分层且自适应的卡片视觉

抽屉 MUST 在保持 180pt 卡片尺寸、12pt 卡间距和既有操作的前提下，使用自适应表面和固定内容类型颜色呈现稳定的标题、内容与元数据层级。

#### Scenario: 用户浏览普通卡片

- **WHEN** 抽屉显示一张卡片
- **THEN** 卡片使用 8pt 圆角和系统自适应表面
- **AND** 标题栏使用与内容类型对应的固定深色背景
- **AND** 标题栏左侧以两行显示内容类型和相对时间
- **AND** 正文区域显示内容类型对应的预览
- **AND** 页脚居中显示字符数、图片尺寸或文件元数据

#### Scenario: 卡片包含来源应用

- **WHEN** 卡片具有非空的 `sourceApp`
- **THEN** 标题栏右侧的固定 34pt 来源槽位优先异步显示可解析的应用图标
- **AND** 应用图标直接使用 macOS 原生轮廓，不叠加自定义圆角底板、描边或阴影
- **AND** 可解析的应用图标放大到 62pt、垂直居中于 Header，并在不改变来源槽位的前提下调整水平偏移
- **AND** 放大部分同时超出 Header 的上、右、下边界
- **AND** 上下各裁切约 8pt，右侧裁切约 10pt
- **AND** 越界部分由 Header 边界和卡片圆角适度截断
- **AND** 放大不得改变来源槽位、标题栏或卡片的布局尺寸
- **AND** 无法解析应用图标时显示稳定的名称首字母回退
- **AND** 辅助功能语义包含来源应用名称

#### Scenario: 卡片缺少来源应用

- **WHEN** 卡片的 `sourceApp` 为空
- **THEN** 来源槽位显示通用应用图标
- **AND** 标题栏其它内容的位置保持不变

#### Scenario: 卡片处于选中或持久状态

- **WHEN** 卡片被选中、置顶或收藏
- **THEN** 选中状态使用 2pt 系统强调色描边且不缩放卡片
- **AND** 置顶使用 `pin.fill`、收藏使用 `star.fill`，并紧随类型文字显示
- **AND** 未激活状态不保留布局宽度
- **AND** 辅助功能分别表达选中、置顶和收藏状态

#### Scenario: 系统外观发生变化

- **WHEN** 系统在浅色和深色外观之间切换
- **THEN** 正文、页脚、分隔线和文字使用系统自适应颜色
- **AND** 标题栏颜色在两种外观下均保持足够文字对比度
- **AND** 状态不得只依赖颜色表达

#### Scenario: 过滤结果在有内容与无内容之间切换

- **WHEN** 用户切换类型过滤且结果从有卡片变为无卡片，或从无卡片变为有卡片
- **THEN** 卡片列表与空状态共用固定 212pt 内容区域
- **AND** 抽屉内容区域的上下边界保持不变
- **AND** 界面不发生纵向布局抖动

### Requirement: 统一的抽屉毛玻璃表面

抽屉 MUST 使用一层连续的毛玻璃背景承载顶部操作和卡片内容，不得通过横跨抽屉的独立材质、底色或分隔线将两个区域视觉分层。

#### Scenario: 用户打开抽屉

- **WHEN** 抽屉同时显示顶部操作和卡片内容
- **THEN** 两个区域共享同一层 AppKit 毛玻璃背景
- **AND** 顶部操作区域不叠加独立的 SwiftUI Material 或不透明背景
- **AND** 顶部操作区域与卡片内容区域之间不显示分隔线
- **AND** 搜索、筛选和菜单按钮仍可使用局部背景表达 Hover、选中与焦点状态

### Requirement: Liquid Glass 风格的头部操作

Header MUST 将搜索、类型筛选和更多菜单组织为独立的紧凑功能组，并在保持 macOS 高密度操作的同时避免旧式凸起控件和无意义的装饰材质。

#### Scenario: 用户浏览折叠状态的 Header

- **WHEN** 搜索尚未展开
- **THEN** 搜索、类型筛选和更多菜单分别使用 34pt 高、10pt 圆角的系统自适应实色表面
- **AND** 控件表面不得直接透出抽屉毛玻璃背景
- **AND** 类型筛选持续显示图标与文字
- **AND** 当前数量使用非交互的次要文字显示
- **AND** 选中筛选使用实色系统强调色、白色文字和更高字重

#### Scenario: 用户展开搜索

- **WHEN** 用户点击搜索按钮或按下 `⌘F`
- **THEN** 搜索从固定左边界由 34pt 展开到 210pt并获得输入焦点
- **AND** 类型筛选的图标、文字和布局结构保持不变
- **AND** 搜索、筛选和数量整组不因展开重新居中
- **AND** 装饰描边和抽屉背景点击层不得拦截搜索按钮的点击

#### Scenario: 用户组合搜索与类型筛选

- **WHEN** 搜索框包含非空搜索词且用户切换类型筛选
- **THEN** 系统更新内容类型过滤条件
- **AND** 系统保留搜索词与展开状态
- **AND** 结果同时满足搜索词和内容类型条件
