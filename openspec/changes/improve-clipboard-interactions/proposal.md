# Change: 改进剪贴板抽屉交互反馈

## Why

当前状态栏图标视觉尺寸偏大，搜索框展开时会改变中心位置，置顶后缺少持久反馈，卡片选择还会强制居中。卡片滚动期间又会同步解码图片、读取展示元数据并叠加多层动态材质；卡片标题、预览、来源和状态缺少稳定的信息层级，降低了界面协调性、操作稳定感和滚动流畅度。

## What Changes

- 缩小状态栏图标的视觉尺寸，但保持系统点击区域不变。
- 保持“搜索框 + 分类按钮 + 数量”整组的原居中基准，让搜索框固定折叠态左边界并只向右展开。
- 在置顶卡片标题栏显示持久的图钉图标和可访问性状态。
- 选择卡片时使用动画执行带边缘间隙的最小必要滚动。
- 将图片预览改为后台下采样并缓存，移除卡片重绘路径中的同步图片解码和文件元数据读取。
- 简化卡片材质、阴影和 Hover 效果，缩小卡片对共享状态的订阅范围。
- 参考同类产品的信息层级重构卡片：使用中性自适应标题栏、来源应用槽位、紧邻类型的置顶/收藏状态、内容预览和居中元数据页脚。
- 来源应用图标直接使用 macOS 原生图标轮廓，不叠加自定义圆角底板、描边或阴影。
- 来源应用图标保留原布局槽位并放大，使上、右、下三边适度超出 Header 后由 Header 与卡片圆角边界截断。
- 过滤结果从有到无时保持卡片内容区域为固定高度，避免抽屉内容纵向抖动。
- 取消顶部操作栏的独立材质、底色和分隔线，让顶部操作与卡片区域共享同一层抽屉毛玻璃背景。
- 按 Liquid Glass 的功能层原则重构 Header：搜索、类型筛选和更多菜单分别使用紧凑的局部实色分组，选中筛选使用实色强调色，数量保持为非交互元数据。
- 搜索框展开时保留完整筛选标签；类型筛选与搜索词可以组合，切换类型不再清空搜索，并支持 `⌘F` 聚焦搜索。
- 修正搜索控件命中层级，装饰描边不参与命中测试，抽屉背景点击不会与 Header 按钮竞争。
- 将类型筛选的强调色选中块改为在按钮之间滑动，并在减少动态效果下即时切换。
- 将每个类型选项的完整圆角区域定义为统一的悬停与点击目标，并在悬停时显示指针光标。
- 将 `primary` 选中块重构为容器中的唯一移动背景，使其不参与 Item 的身份和命中；每个稳定 Item 独立管理完整区域的 Hover 与点击，并使用系统声明式 pointer style（macOS 15+）或 AppKit cursor rect（macOS 13/14）持久声明光标。
- 将数量统计放入固定宽度元数据槽，避免数字位数变化带动居中控件组水平抖动。
- 保持现有顶部搜索、五类筛选、数量和更多菜单的能力与布局原则，不增加没有对应功能的加号或锁定状态。

## Impact

- Affected specs: `menu-bar-access`, `clipboard-drawer`
- Affected code:
  - `Sources/PasteDeck/App/AppDelegate.swift`
  - `Sources/PasteDeck/Views/MainWindow.swift`
  - `Sources/PasteDeck/Views/ClipCardView.swift`
  - `Sources/PasteDeck/Views/CardGridView.swift`
  - `Sources/PasteDeck/Services/CardPreviewCache.swift`
- 不修改数据模型、持久化格式、排序规则或卡片尺寸。
- 来源应用图标使用现有 `sourceApp` 的稳定回退表示；可靠的 Bundle ID 采集与持久化迁移不在本次范围内。
