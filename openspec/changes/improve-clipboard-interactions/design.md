## Context

PasteDeck 使用 `NSStatusItem` 提供菜单栏入口，并以 SwiftUI 横向卡片流呈现剪贴板历史。现有交互已具备基本功能，但部分视觉和滚动行为会造成不必要的位移或状态不明确。

## Goals / Non-Goals

### Goals

- 使菜单栏图标与其它系统状态项的视觉重量协调。
- 保持头部控件组原有居中布局，同时让搜索框左边界稳定。
- 让置顶状态在卡片上持续可见，且不只依赖颜色。
- 保持用户当前浏览位置，仅在必要时滚动。
- 避免卡片滚动和选中刷新时在主线程重复解码图片或读取文件元数据。
- 在不改变卡片尺寸和核心操作的前提下，建立清晰、安静且适配深浅色的卡片信息层级。

### Non-Goals

- 不改变置顶排序语义。
- 不改变搜索、筛选和卡片选择的数据流。
- 不新增 toast、文字标签或卡片尺寸。
- 不处理列表视图、iCloud 或持久化性能问题。
- 不在本次变更中引入第三方图片加载框架或修改原始剪贴板图片数据。
- 不新增没有真实业务语义的“添加”或“锁定”控件。
- 不为来源图标新增 Bundle ID 字段、Core Data 迁移或图像二进制持久化。

## Decisions

### 状态栏图标

继续使用 `doc.on.clipboard` SF Symbol，将视觉字号从 16pt 调整为 14pt，并设置按比例缩小。系统 `NSStatusBarButton` 的点击区域和 `PasteDeck` 辅助功能描述保持不变。

### 搜索框

保留“搜索框 + 分类按钮 + 数量”整组在折叠状态下的原居中布局。记录折叠态整组宽度并以此计算稳定的居中起点；搜索框从 34pt 展开到 210pt 时，该起点和搜索框左边界不动，过滤器与数量仅被向右推开。折叠态使用语义化按钮，并提供 tooltip 与 VoiceOver 标签。

### 置顶反馈

在卡片标题栏的类型文字右侧按需显示状态图标。置顶时显示白色 `pin.fill`，收藏时显示 `star.fill`；未激活的状态不创建占位，因此时间行始终从左侧连续显示。状态图标提供对应辅助功能语义。正常动态效果下使用短促淡入和轻微缩放；开启减少动态效果时仅改变透明度。

### 卡片滚动

`ScrollViewReader` 在选中项变化时调用不带 anchor 的 `scrollTo(item.id)`。卡片区域采用统一的 16pt 上下左右 padding，并以“180pt 卡片 + 上下各 16pt”显式限定为 212pt 高；每个滚动项由“16pt 透明区 + 卡片 + 16pt 透明区”组成，透明区同时承担首尾水平 padding 和自动滚动的有效视窗内缩。`LazyHStack` 使用负间距抵消相邻透明区，从而保持原有 12pt 卡片视觉间距，不再叠加额外水平 padding。SwiftUI 仅在整个滚动项未完整可见时执行带动画的必要滚动；已完整可见时保持原位。该规则同时适用于鼠标点击和键盘选择。仅在开启减少动态效果时不包裹滚动动画。

### 卡片预览性能

使用进程内预览缓存按 `ClipItem.id` 保存卡片展示数据。图片通过 ImageIO 在后台线程按卡片实际显示尺寸的 Retina 上限进行下采样，主线程只接收已缩小的图像和尺寸文本；文件大小与扩展名同样在后台解析并缓存。卡片 `body` 不再调用 `NSImage(data:)`、访问文件系统或创建 Formatter。

抽屉外层继续承担毛玻璃效果，卡片和页脚改为稳定的自适应颜色，避免滚动时叠加多层 backdrop material。Hover 只改变描边，不再缩放卡片或改变阴影半径。卡片动作由父视图以闭包传入，卡片不直接订阅整个 `ClipboardViewModel`。

### 抽屉与卡片视觉层级

保留 280pt 抽屉、60pt 顶部区域、180pt 卡片、12pt 卡间距和 16pt 卡片区域边距。顶部继续显示“搜索 + 五类筛选 + 数量”整组，折叠时以抽屉为中心，右侧更多菜单独立定位；不因参考稿隐藏既有高频筛选能力。

整个抽屉只使用 AppKit 外层 `NSVisualEffectView` 提供的一层 `.popover` 毛玻璃。SwiftUI 顶部操作区域保持透明，不再叠加 `.ultraThinMaterial`、独立底色或底部分隔线；卡片列表和空状态同样保持透明，使顶部操作与内容区域成为一个连续表面。搜索、筛选和更多按钮仍可使用局部控件背景表达 Hover、选中和输入焦点，但这些局部反馈不得形成横跨抽屉的区域分层。

Header 采用 Liquid Glass 的“内容层之上的功能层”原则，但不在 macOS 13 最低部署目标上仿造新系统的光学折射。搜索、类型筛选和更多菜单分别形成 34pt 高、10pt 圆角的紧凑局部实色组：普通状态使用系统自适应 `controlBackgroundColor`，Hover 使用 `unemphasizedSelectedContentBackgroundColor`，选中筛选使用实色系统强调色与白色文字。轻微描边和阴影建立悬浮关系，数量作为普通次要文字，不包裹成可点击胶囊。搜索从固定左边界由 34pt 展开至 210pt，筛选按钮始终保留图标与文字，避免展开时结构重排。类型筛选只更新 `contentFilter`，不清空搜索词，允许搜索与类型组合；`⌘F` 直接展开并聚焦搜索。所有装饰描边禁用命中测试，抽屉背景点击手势放到内容后方，避免与 Header 按钮竞争。

卡片使用 8pt 圆角与系统自适应表面，并拆成稳定的三层：46pt 语义色标题栏、110pt 内容预览、24pt 居中元数据页脚。文本、图片、文件和颜色分别使用深蓝、深青、石墨和琥珀色标题栏，以形状图标与文字共同表达类型；标题栏左侧以两行显示内容类型和相对时间，右侧保留 34pt 来源应用图标布局槽。真实来源图标直接按 macOS 原生轮廓呈现，不增加自定义圆角底板、描边或阴影；其视觉尺寸放大到 62pt，垂直居中于 46pt Header，并在不改变布局槽的前提下调整水平偏移，使上下各裁切约 8pt、右侧裁切约 10pt，再由 Header 边界和卡片外层圆角裁切。置顶与收藏使用 `pin.fill`、`star.fill` 紧随类型文字显示，未激活时不保留空白槽位。选中态使用 2pt 系统强调色描边，不做缩放或位移。

卡片列表与空状态共用固定 212pt 内容区域。过滤切换只替换区域内部内容，不改变抽屉纵向布局；这也让 180pt 卡片及其上下各 16pt padding 始终保持一致。

当前数据只保存来源应用的本地化名称，无法可靠定位已安装应用。来源槽位优先从仍在运行的应用和常见应用安装目录异步解析真实图标，并按名称缓存；无法解析时使用名称首字母，无来源时使用通用应用图标。该方案改善常见来源的识别度，但不把名称解析包装成可靠身份，Bundle ID 采集和持久化仍作为独立数据能力处理。卡片继续通过上下文菜单执行动作，不在现有整卡点击层下增加不可点击的表面按钮。

## Alternatives Considered

- `Pinned` 文字标签：识别明确，但占用预览空间并增加视觉噪音。
- 卡片强调色边条和 toast：反馈过强，且会与选中边框竞争。
- 手工测量卡片和视窗坐标：可精确控制滚动，但扩展滚动目标即可复用原生 `scrollTo` 语义，无需维护逐卡片几何状态。
- 自定义菜单栏图标：维护深浅色和多分辨率资源的成本高于本次收益。
- 仅调整滚动动画曲线：可以改变主观速度，但无法解决同步解码和图层合成造成的掉帧。
- 缓存完整原图：实现简单，但无法降低大图解码后的内存与合成成本，因此缓存的是下采样预览。
- 完全复刻竞品的任意品牌色标题栏：颜色若不绑定内容类型会形成错误语义；本次仅使用四种固定、可预测的内容类型颜色。
- 在工具栏增加加号或在卡片增加锁图标：PasteDeck 当前没有对应能力，会制造错误预期。
- 按来源名称同步查找并加载真实 App 图标：名称可能本地化或重名，且会把 Workspace 查询带回卡片渲染路径；因此仅异步尽力解析并缓存。

## Risks / Trade-offs

- 14pt 图标在不同 macOS 版本上的视觉重量可能略有差异；保留 SF Symbol 和系统按钮可降低差异。
- 无 anchor 的 `scrollTo` 具有最小距离显示完整目标的系统语义；统一的 16pt 透明边距使落位后不贴边，仍需实机回归 `LazyHStack`、动画和不同 macOS 版本下的实际呈现。
- 状态图标出现时会占用类型行的尾部空间；类型文字保持左侧锚定并限制为单行，来源图标仍固定在右侧。
- 进程内预览缓存会增加少量常驻内存；使用 `NSCache` 交由系统在内存压力下回收，并把预览最长边限制为 360px。
- 后台任务完成前图片卡片会短暂显示占位图；缓存命中后不再重复出现。
- 来源首字母不等同于真实 App 图标，但不会误认应用或引入数据迁移；后续可在持久化 Bundle ID 后替换。
- 放大的真实来源图标会被 Header 的上、右、下边界有意裁切；34pt 布局槽保持不变，避免影响标题宽度与卡片布局。

## Verification

- 运行 `swift test`，确保现有模型、存储和 ViewModel 行为无回归。
- 构建并启动应用，比较状态栏图标与相邻系统图标。
- 验证整组折叠态保持居中，搜索框展开前后左边界位置不变。
- 验证置顶和取消置顶时图钉状态、排序和辅助功能语义一致。
- 验证卡片区域上下左右均为 16pt padding。
- 分别通过鼠标和键盘选择完整可见、左侧半露和右侧半露卡片，验证滚动动画、距离和 16pt 边缘间隙。
- 开启减少动态效果后，验证置顶图标只淡入且卡片滚动不使用动画。
- 使用 Accessibility Inspector 验证搜索按钮、图钉状态和状态栏描述。
- 使用纯文本、图片和文件三组历史验证持续横向滚动；通过 Time Profiler 确认主线程滚动栈不再执行图片解码或文件属性读取。
- 在浅色、深色及高对比度环境验证标题栏、正文、页脚、选中描边与状态图标层级。
- 验证有来源、无来源、长来源名称以及置顶/收藏组合时，标题和来源槽位均不发生布局跳动。
